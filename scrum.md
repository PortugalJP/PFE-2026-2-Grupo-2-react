## 5. Sprints

### Sprint 1 — Planejamento
**Período:** 03/11 a 09/11 (Semana 1)

**Objetivo:** Planejar o projeto, definir o escopo e distribuir as responsabilidades entre o time.

**Atividades:**
- Definição do escopo e dos requisitos do projeto
- Divisão das páginas/módulos entre os desenvolvedores
- Definição da estrutura de pastas e componentes do projeto React
- Configuração do ambiente de desenvolvimento (VS Code)

**Entregáveis:**
- Escopo e backlog definidos
- Funções atribuídas por desenvolvedor
- Ambiente de desenvolvimento configurado

---

### Sprint 2 — Programação e Adaptação ao React
**Período:** 10/11 a 16/11 (Semana 2)

**Objetivo:** Desenvolver as páginas e adaptar o projeto para React.

**Atividades:**

| Desenvolvedor | Atividade |
|---|---|
| Gabriel Vangeloti | Desenvolvimento e adaptação da página **Início** |
| João Pedro Portugal | Desenvolvimento e adaptação da página **PKZ** |
| Maria Eduarda Oros | Desenvolvimento e adaptação da página **One to One** |
| Lucas Corrêa | Desenvolvimento e adaptação da página **Fisioterapia** |
| Felipe Villar | Desenvolvimento e adaptação da página **Agendamento** |
| Arthur de Sousa | Desenvolvimento e adaptação da página **Equipe** |

- Conversão do código existente para componentes React
- Alinhamentos e resolução de dúvidas em reuniões pelo Google Meet

**Entregáveis:**
- Páginas desenvolvidas e adaptadas ao React

> **Observação:** durante esta sprint, o projeto foi desenvolvido e armazenado **localmente**, sem versionamento no GitHub.

---

### Sprint 3 — Commits e Entrega
**Período:** 17/11 (Semana 3 — dia da entrega final)

**Objetivo:** Versionar o projeto no GitHub, finalizar os ajustes e realizar a entrega final.

**Atividades:**
- Revisão final do código de cada módulo
- Realização dos **commits** no GitHub por todos os desenvolvedores
- Teste final do projeto
- Publicação do site (Vercel)
- Entrega final do projeto React

**Entregáveis:**
- Projeto versionado no GitHub
- Site publicado no Vercel
- Entrega final em **17/11**
